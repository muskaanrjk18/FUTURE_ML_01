# Sales and Demand Forecasting

## Project Overview
This project focuses on analyzing historical sales data and forecasting future sales using Machine Learning.

## Objectives
- Analyze historical sales data.
- Clean and preprocess the dataset.
- Identify monthly sales trends.
- Train a Linear Regression model.
- Predict future sales for the next three months.
- Evaluate model performance.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Machine Learning Algorithm
Linear Regression

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score

## Project Structure
- data: Original and processed sales datasets.
- notebooks: Jupyter Notebook.
- outputs: Forecast report and visualizations.

## How to Run
1. Clone the repository.
2. Install the required libraries.
3. Open the Jupyter Notebook.
4. Run all cells in sequence.
5. Check the forecast report in the outputs folder.

## Note
This project uses Linear Regression as a basic forecasting approach. Predictions are based on historical monthly sales trends.
